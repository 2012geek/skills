# 腾讯文档登录二维码获取

快速获取腾讯文档登录二维码的工具。

## 使用方法

```bash
# 进入目录
cd /Users/chenlening/workspace/skills/tencent-doc-download

# 获取二维码（截图保存到桌面）
node scripts/get-qr-code.js

# 或者指定输出路径
node scripts/get-qr-code.js --output=/path/to/qr.png
```

## 工作原理

脚本会自动完成以下步骤：

1. ✅ 打开腾讯文档首页
2. ✅ 点击右上角"登录"按钮
3. ✅ 同意用户协议
4. ✅ 点击微信登录图标
5. ✅ 点击 "Log in now" 按钮
6. ✅ **点击 "Agree" 按钮（关键步骤！）**
7. ✅ 等待二维码出现
8. ✅ 检测并验证二维码
9. ✅ 截图保存

## 关键改进

- **自动检测二维码** - 只有检测到二维码才会保存截图
- **完整的登录流程** - 包含点击 "Agree" 按钮的关键步骤
- **错误处理** - 如果未检测到二维码，会保存调试截图并报错

## 常见问题

**Q: 为什么之前获取的二维码不对？**
A: 之前漏掉了点击 "Agree" 按钮的步骤。这个脚本已经包含了这个关键步骤。

**Q: 如何验证二维码是否正确？**
A: 脚本会自动检测页面是否有大于 200x200 的图片或 canvas，并检查页面是否包含"扫码"文字。

**Q: 登录会话保存在哪里？**
A: 保存在 `.tencent-docs-session/` 目录，下次使用会自动恢复登录状态。

## 技术细节

- 使用 Puppeteer 自动化浏览器
- 使用系统 Chrome 浏览器
- 自动检测二维码（检查图片/canvas 尺寸和页面文本）
- 保存会话数据，避免重复登录
