# GitCode PR Review Comment Repair

Automatically repair GitCode PR review comments using LLM to generate fixes, reply to each comment with solutions, and commit with `git commit --amend`.

## Features

- **Hybrid Status Detection**: Tries GitCode API first, falls back to web scraping
- **LLM-Powered Fixes**: Uses Anthropic Claude to analyze and generate code fixes
- **Smart Logic Detection**: Identifies when review comments are flawed and responds appropriately
- **Automated Replies**: Posts replies to review comments via GitCode API
- **Git Amend**: Commits all fixes with `git commit --amend`
- **Summary Table**: Outputs detailed summary with fix links

## Installation

This skill is part of the mylerobot-doc project. No additional installation needed.

## Prerequisites

1. **GitCode Personal Access Token** with `repo` and `pull_request` scopes
2. **Anthropic API Key** for Claude LLM access
3. **Node.js** and required npm packages

## Configuration

Create or update `config.json` in your project root:

```json
{
  "gitcode": {
    "token": "your_gitcode_token_here",
    "owner": "openeuler",
    "repo": "lerobot_ros2",
    "baseUrl": "https://api.gitcode.com"
  },
  "anthropic": {
    "apiKey": "sk-ant-your-key-here"
  }
}
```

## Usage

### Option 1: Slash Command (Recommended)

```
/gitcode-repair-pr
```

You will be prompted to enter the PR URL.

### Option 2: Direct Script

```bash
node skills/gitcode-code-review-repair/scripts/repair-pr.js
```

### Option 3: With PR URL Argument

```bash
node skills/gitcode-code-review-repair/scripts/repair-pr.js https://gitcode.com/openeuler/lerobot_ros2/pull/50
```

## Workflow

1. **Parse PR URL** → Extract owner, repo, PR number
2. **Get Review Status** → Fetch resolved/total counts (API or scraping)
3. **Check Unresolved** → Calculate remaining unresolved comments
4. **Fetch Comments** → Get all unresolved review comments
5. **Generate Fixes** → Use Claude to analyze and fix each comment
6. **Reply to Comments** → Post fix replies via GitCode API
7. **Apply Fixes** → Edit files with generated fixes
8. **Commit** → Use `git commit --amend` to update commit
9. **Summary** → Display table with all fixes and links

## Troubleshooting

### Missing API Keys

**Error**: `Missing gitcode.token in config.json` or `Missing anthropic.apiKey`

**Solution**: Add the required keys to `config.json` as shown in Configuration above.

### Git Amend Fails

**Error**: `Git operation failed`

**Solution**: Ensure you have uncommitted changes to amend. The skill uses `git commit --amend` which requires existing changes to modify.

### Scraping Fails

**Error**: `Could not find review status div on page`

**Solution**: The PR page HTML may have changed. The skill will attempt to use API-only mode as fallback.

### LLM Rate Limits

**Error**: `Anthropic API rate limit exceeded`

**Solution**: Wait a moment and retry, or check your Anthropic account for rate limits.

## Dependencies

- `@anthropic-ai/sdk` - Anthropic Claude API client
- `puppeteer` - Web scraping for status detection (fallback)
- Node.js built-in modules: `fs`, `path`, `https`, `readline`, `child_process`

Install dependencies:

```bash
npm install @anthropic-ai/sdk puppeteer
```
