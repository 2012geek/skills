# GitCode PR Review Comment Repair

This command automatically repairs GitCode PR review comments by:

1. Parsing PR link and extracting owner, repo, PR number
2. Fetching review comment status (resolved/total count)
3. Getting unresolved review comments
4. Using LLM (Anthropic Claude) to generate fixes
5. Replying to each comment with fix details
6. Committing fixes with `git commit --amend`
7. Outputting summary table with fix links

## Usage

Run this command without arguments:
```
/gitcode-repair-pr
```

The command will prompt for:
- PR URL (e.g., https://gitcode.com/openeuler/lerobot_ros2/pull/50)

## Configuration

Requires `config.json` in project root with:

```json
{
  "gitcode": {
    "token": "your_gitcode_token",
    "owner": "openeuler",
    "repo": "lerobot_ros2",
    "baseUrl": "https://api.gitcode.com"
  },
  "anthropic": {
    "apiKey": "your_anthropic_api_key"
  }
}
```

## Workflow

1. **Parse PR URL**: Extract owner, repo, PR number from URL
2. **Get Review Status**:
   - Try GitCode API first
   - Fall back to web scraping for "评审意见已解决X/Y" text
3. **Calculate Unresolved**: `unresolved = total - resolved`
4. **If All Resolved**: Show success message and exit
5. **Fetch Unresolved Comments**: Get each review comment with file, line, and content
6. **Generate Fixes** (for each comment):
   - Use Claude to analyze code and review comment
   - Generate fix or detect flawed review logic
   - Prepare reply with fix details
7. **Apply Fixes**:
   - Edit/modify files based on fix suggestions
   - Reply to each review comment with solution
8. **Commit**: Use `git commit --amend` to update commit
9. **Summary**: Output table with all fixes and links

## Reply Format

For code fixes:
```
检视意见已经修复，具体修复代码和方案描述如下：

**修复方案**:
[description of the fix]

**修改文件**: `path/to/file.py`

**上下文代码**:
```python
# Before
[original code]

# After
[fixed code]
```

---
🤖 Generated by gitcode-code-review-repair
```

For flawed review logic:
```
**关于此检视意见的说明**:

[explanation of why the review comment may be incorrect or needs clarification]

[additional context or questions for the reviewer]

---
🤖 Generated by gitcode-code-review-repair
```

## Tips

- Ensure `git status` is clean before running (will use `--amend`)
- Review generated fixes before allowing them to be applied
- Use `--dry-run` flag to preview changes without modifying files
- Check the summary table for links to each review comment reply

## Troubleshooting

**API Error**: Check GitCode token in config.json has `repo` and `pull_request` scopes

**LLM Error**: Ensure Anthropic API key is valid and has sufficient credits

**Commit Amend Error**: Make sure you're on the correct branch with uncommitted changes

**Scraping Fails**: If web scraping fails, ensure PR page is accessible and HTML structure hasn't changed
