# 智能溢出检测与调整技术方案

> 版本: 1.0
> 日期: 2026-02-28
> 状态: 待审核

## 一、背景

将 Markdown 转换为 Slidev 演示文稿时，可能出现内容溢出问题：
- 文字过多超出页面
- 图片太大
- 布局不合理

传统硬编码方案无法适应复杂场景，本方案采用 **LLM 驱动的智能检测与调整**。

### 2.2 LLM 智能检测

使用视觉 LLM (GLM-4V / Claude) 分析渲染后的截图：

**输入:**
- 原始 Markdown
- 幻灯片截图 (base64)
- 当前主题信息

**输出:**
```json
{
  "overflow": true,
  "score": 65,
  "issues": ["内容过多", "图片太大"],
  "suggestion": "建议拆分为两页",
  "needsAdjustment": true
}
```

### 2.3 LLM 多方案生成

当自动调整失败时，LLM 生成 3 种解决方案：

| 方案 | 策略 | 说明 |
|------|------|------|
| A | 拆分 | 将内容拆到多页 |
| B | 精简 | 删除次要内容 |
| C | 布局 | 调整为两栏等布局 |

### 2.4 人机协作

当 LLM 多次调整仍未达标时，提供以下选项：

- [1-3] 选择 LLM 提供的方案
- [4] 查看原图/当前版本
- [5] 手动编辑 Markdown
- [6] 跳过此页 (标记为待优化)
- [7] 降低目标分数继续
- [0] 终止生成

## 三、核心模块

### 3.1 IntelligentOverflowDetector
- 使用 Puppeteer 渲染页面
- 调用视觉 LLM 分析截图
- 返回溢出检测结果

### 3.2 IntelligentContentAdjuster
- 调用 LLM 调整内容
- 支持多种调整策略

### 3.3 HumanCollaborationManager
- 生成多个方案
- 渲染预览
- 等待用户选择
- 支持手动编辑

### 3.4 IntelligentVerifyLoop
- 整合上述模块
- 实现完整的验证循环
- 处理所有页面
- 生成优化报告

## 四、支持的 LLM 提供商

| 提供商 | 模型 | 视觉能力 | 备注 |
|--------|------|----------|------|
| GLM | glm-4v-flash | ✅ | 默认，性价比高 |
| Anthropic | claude-sonnet-4 | ✅ | 高质量 |
| OpenAI | gpt-4o | ✅ | 备选 |

## 六、CLI 命令

```bash
# 基础生成
node cli.js generate slides.md

# 智能验证（交互模式）
node cli.js generate slides.md --smart-verify

# 智能验证（非交互）
node cli.js generate slides.md --smart-verify --no-interactive

# 指定 LLM
node cli.js generate slides.md --smart-verify --llm anthropic

# 导出 PDF
node cli.js generate slides.md --export pdf

# 完整流程
node cli.js generate slides.md \
  --theme neocarbon \
  --smart-verify \
  --export pdf
```

## 八、风险与应对

| 风险 | 应对 |
|------|------|
| LLM API 限流 | 重试机制 + 缓存 |
| 视觉模型判断不准确 | 多次验证 + 人工干预 |
| 生成时间较长 | 进度显示 + 并行处理 |
| 成本过高 | 可选功能 + 智能跳过简单页面 |

## 九、后续优化

1. **缓存机制** - 相似内容复用结果
2. **并行处理** - 多页同时验证
3. **增量验证** - 只验证变更页面
4. **离线模式** - 本地模型支持
