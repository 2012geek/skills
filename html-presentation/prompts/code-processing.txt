## 处理任务

### 1. 代码注释添加

为代码添加必要的注释：
- 函数/类的功能说明
- 关键参数的解释
- 重要逻辑的说明
- 返回值的说明

**注释风格**：
```python
# 计算两个数的和
def add(a, b):
    return a + b  # 返回计算结果
```

### 2. 代码结构优化

如果代码过长（>20 行），建议：
- 提取核心部分展示
- 使用 // ... 省略部分代码
- 说明完整代码的位置

### 3. 高亮建议

建议需要高亮的关键行：
- 函数定义
- 关键逻辑
- 返回语句
- 异常处理

### 4. 分步展示建议

对于复杂代码，建议分步展示：
- 第一步：初始化
- 第二步：处理逻辑
- 第三步：结果处理

## 语言特定指南

### Python
- 添加类型注解提示
- 说明装饰器的用途

### JavaScript/TypeScript
- 说明箭头函数的优势
- 解释异步处理 (async/await)
- 说明解构赋值

- 解释命令的用途
